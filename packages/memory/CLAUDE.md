# @atlas/memory

Memory Service (Support) — autoridade única de conhecimento persistente (ADR-0011).

- `createMemoryService({ storage }): Promise<MemoryService>` → `remember/forget/list/prompt`. Carrega os fatos **uma vez** na criação (leitura síncrona) e persiste por **write-through**.
- **Deduplicação determinística (SPEC-0022)**: `remember(text, source?)` retorna `Promise<{ fact: Fact; created: boolean }>` (mudança **não-aditiva**, antes `Promise<Fact>`). Um helper puro interno `normalize(text)` (`trim` → `toLowerCase` → colapso de `\s+` para `" "`, sem IO, **não** sobe a `@atlas/contracts`) decide duplicata: se `normalize(text)` coincidir com a normalização de um fato já carregado, `remember` faz **no-op idempotente** — não cria `Fact`, não chama `storage.save`, não promove `source` — e devolve `{ fact: existente, created: false }`. Sem duplicata, comportamento anterior (cria, `push`, `storage.save`) e `{ fact: novo, created: true }`. Vale para todo `source` (`'user'` e `'learned'`). Só protege **escritas novas**: normalização é só espaço + caixa (sem acento/pontuação/semântica).
- **Consolidação determinística do acervo legado (SPEC-0023)**: `dedupe(options?: { apply?: boolean }): Promise<DedupeReport>` (`@atlas/contracts` exporta `DedupeReport { applied; groups }`/`DedupeGroup { survivor; duplicates }`) — membro **aditivo** de `MemoryService`. Reusa o **mesmo** `normalize(text)` acima (sem duplicar a função) para agrupar `facts` por normalização; grupo com ≥ 2 fatos é duplicata. Dry-run por default (`apply` ausente/`false`): só computa e relata `groups`, sem mutar `facts` nem chamar `storage.save`. `apply: true`: sobrevivente por grupo = o de **menor `createdAt`** (comparação lexicográfica de string ISO — `createdAt` sempre `toISOString()`, coerente com ordem cronológica), empate desempata pelo **menor índice em `facts`** (ordem de carga); as demais entradas do grupo são removidas, `facts` reconstruído preservando ordem de carga, `storage.save(facts)` chamado **1x**. Sobrevivente preservado **intacto** (`id`/`text`/`createdAt`/`source`) — sem merge de campos, sem promover/rebaixar `source`, sem reescrever `text`. Acervo sem duplicata é **no-op** determinístico (`groups` vazio, `applied: false`, `storage.save` **não** chamado mesmo com `apply: true`) — idempotente (rodar 2x seguidas = a 2ª é no-op). Fecha, para o acervo legado, a garantia que a SPEC-0022 deu só a escritas novas. `remember`/`forget`/`list`/`prompt` inalterados.
- **Busca/recuperação determinística (SPEC-0027)**: `search(query: string, options?: { readonly limit?: number }): readonly Fact[]` — membro **aditivo** de `MemoryService`. Puro e síncrono, opera só sobre os `facts` já carregados (nenhum IO, mesmo molde de `list`/`prompt`). Reusa o **mesmo** `normalize(text)` interno (SPEC-0022) para tokenizar consulta e fato; ranking por overlap de tokens (`score = |tokens(query) ∩ tokens(fact)|`), exclui `score = 0`, ordena por `score` desc, empate desempatado pela ordem de carga (índice ascendente em `facts`, mesmo critério do `dedupe`). `options.limit` opcional corta os `N` primeiros já ordenados; ausente devolve todos com overlap. Consulta vazia/sem tokens após `normalize` devolve `[]`. Retorno `Fact[]` homogêneo com `list()`, **sem** expor scores. **Não** altera `prompt()`/o caminho de injeção na geração — consumo por `search` a partir da consulta do turno no Cognitive Core segue fatia futura. CLI: `atlas memory search "<consulta>"`.
- **Categorias de conhecimento (SPEC-0029)**: `MemoryCategory = 'fact' | 'episode' | 'project'` (`@atlas/contracts`); `Fact` ganha `category?`/`subject?`, ambos **opcionais** (ausência de `category` ≡ `'fact'`, acervo legado não é migrado/revalidado no `load`). `remember(text, source?, options?: { category?; subject? })` — terceiro parâmetro opcional, 100% compatível com chamadores de 1/2 argumentos — **garante dentro do módulo** (Artigo 11, antes de qualquer mutação/`storage.save`) que `category: 'project'` exige `subject` válido e que `subject` só é válido com `category: 'project'`; lança `MemoryError` (classe já existente) nos dois sentidos. Um `subject` que colapse para vazio após `normalize` (`''`/`'   '`/`'\t\n'`) conta como **ausente e inválido**, não "sem projeto". A **chave de duplicata** (SPECs 0022/0023) passa a incluir `normalize(category ?? 'fact')` + `normalize(subject ?? '')` + `normalize(text)`, reusada em `remember`/`dedupe`, para o mesmo texto em categorias/projetos diferentes não colapsar. `list(options?: { category? })` filtra (ausente ≡ `'fact'`). `prompt()` compõe **seções por categoria** (`fact → project → episode`, separadas por `\n\n`, vazias omitidas); a seção `fact` é **byte a byte idêntica** à anterior (não-regressão); a seção `project` agrupa por `subject` (subcabeçalho `[projeto <subject>]`, texto original) em ordem de **primeira ocorrência** na carga. `dedupe`/`search`/`forget` inalterados em assinatura; `search` não filtra por categoria (fora de escopo). CLI: `atlas remember "<texto>" --category <c> [--subject <projeto>]`, `atlas memory list [--category <c>]`.
- **Injeção guiada pela consulta do turno (SPEC-0030)**: `prompt(options?: { readonly query?: string; readonly limit?: number }): string | undefined` — parâmetro **opcional/aditivo**; sem `options`/`limit`, ou com `facts.length <= limit`, o retorno é **byte a byte idêntico** ao dump completo de hoje. Com `limit` e acervo maior, um helper puro top-level `selectFacts(facts, searchFn, options)` reusa `service.search` (nenhuma segunda definição de relevância) para selecionar os relevantes à `query` primeiro, completa o orçamento com os fatos restantes em **ordem de carga** (piso: nunca menos que `min(total, limit)`) e reordena a seleção final pela ordem de carga original antes de `composePrompt` — a relevância decide quem entra, nunca a ordem/formato das seções (`fact → project → episode`, SPEC-0029, preservadas). `prompt` continua síncrono/puro/sem IO, não muta `facts`. Consumido por `@atlas/cognitive` via `CognitiveCoreDeps.memoryPrompt(query, limit)`.
- Fatia mínima (SPEC-0009): só **fatos/preferências explícitos** (`Fact = { id, text, createdAt, source? }`). Categorias entregues na SPEC-0029; sem retenção/relações — SPECs futuras (busca entregue na SPEC-0027).
- **Proveniência (SPEC-0020/ADR-0016)**: `remember(text, source?)` aceita `source?: 'user' | 'learned'` (default `'user'` — chamadores de 1 argumento intactos) e persiste no `Fact`. `'learned'` é usado pela **borda** ao gravar fatos propostos pelo Cognitive ao fim de um turno (Aprendizado, Etapa 6); a autoridade de gravação segue exclusiva deste serviço. Fatos legados sem `source` seguem legíveis (tratados como `'user'` na exibição).
- Persistência atrás de uma **porta injetável** `MemoryStorage` (`load`/`save`), interna ao package: `createFileMemoryStorage(path)` (JSON) é o default; testes injetam um fake em memória (sem IO real). A porta **não sobe** a `@atlas/contracts`.
- `prompt()` enquadra os fatos para **injeção na geração** do Cognitive (ADR-0011, estende ADR-0010): o core passa `memory.prompt()` como `memoryPrompt`. O Cognitive não conhece o conceito de Memory.
- **Não** decide estratégia, **não** controla o fluxo cognitivo, **não** chama o Model Gateway, **não** considera toda conversa como memória permanente (Module Catalog).
- Memória (persistente) × Contexto (temporário) são distintos (Glossary). Depende só de `@atlas/contracts`. Erro: `MemoryError` (`AtlasError` code `ATLAS_MEMORY`).
